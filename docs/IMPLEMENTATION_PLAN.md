## 2. 施工依赖与登记

1. C1 先再次核验当前 TheArchive、BepInEx／interop 引用与 API；按真实加载方式决定使用 ArchiveModule 还是 BepInEx 入口注册，避免同一模块被注册两次。原型通过后明确运行版本范围，不能把当前程序集版本直接等同于 Thunderstore 包版本。
2. C1 已把计划身份转入 repo.json 的 `Modules`，登记实际 `SourceRoot`、`TestsRoot`、`ExternalReferences` 与 `DependencyDetails`，并用 `ModControl.Resources` 数据模块随 DLL 安装模块分组定义。只有真实实现、测试与入口存在时才保持活动登记；工具不把 `out` 或本地构建解释为已发布插件。
3. C2 使用原本生产操作模型做测试，不维护一份镜像实现；故障注入验证拒绝、恢复与状态报告，不仅验证 getters／setters。
4. C3 选择目标前检查其仓 README、repo.json、Git 状态、运行读取位置和保存调用；先形成小范围配置接入清单，再改对应仓。当前不指定玩家可调参数，也不擅自将所有配置反射暴露。
5. C4 复用原 MOD 的配置归属，为必要保存后端增加明确能力；多个原 MOD 共用 CFG 时共同检查。没有共享文件保护与完整退出路径验证，不开放写入。
6. 跨仓代码变化按工作区关联表回归；不修改共用工具实现以便伪装现有入口支持新模块。确需修改工具时，按届时功能仓及实际入口范围重建回归并更新登记。

## 3. 原型验收矩阵

| 场景 | 必须证明的结果 | 验证层级 |
| --- | --- | --- |
| 打开／关闭菜单、切换页面 | 草稿保留但不自动应用／保存，输入焦点恢复，目标状态不被无意改变 | 离线状态模型＋游戏实测 |
| 有效与非法草稿 | 合法变更先验证，越界／枚举／跨项约束拒绝且不发生部分写入 | 离线策略＋目标接口 |
| 临时应用／恢复 | P 与相关框架文件逐项不变，R 由原 MOD 确认；恢复已保存值走相同校验 | 离线＋文件指纹＋游戏实测 |
| 保存为默认 | P 正确更新、R／T 保持，页面明确差异，其他键与共享配置不变 | 故障注入＋文件指纹＋游戏实测 |
| 退出与重启 | 正常退出不泄漏 T；下次按 P 启动；异常退出不会因无条件退出保存污染 P | 保存路径核验＋受控终止＋正常游戏重启 |
| 进出关卡、对象销毁 | 不持有失效对象，不执行过期请求；本进程临时偏好按原 MOD 生命周期正确重绑 | 离线生命周期＋游戏实测 |
| 外部配置／热键变更 | 过期草稿被拒绝，玩家可刷新重新确认，不能静默覆盖新值 | 离线冲突＋游戏实测 |
| 存储失败／恢复失败 | 原文件保留，状态如实报告；未确认状态停止后续写操作 | 受控文件后端故障注入 |
| 框架／目标缺失、版本不兼容 | 本模块能力停止且有原因，其他模块页面与原功能 MOD 独立运行 | 离线类型加载＋游戏组合验证 |
| 单模块异常、重复点击 | 异常局限于当前适配器，操作不重入，不重复提交 | 离线操作协调器＋游戏实测 |
| 房主／客户端状态变化 | 权限在提交时复核；没有同步依据的操作保持只读 | 受控权限＋实际联机（涉及后才声明通过） |

“正常退出不写入临时值”必须覆盖原 MOD 自身 Save、TheArchive 自动保存和共享 ConfigFile 其他使用者。只比较点击应用瞬间的 CFG 或只测试游戏崩溃，不足以通过。相关框架和配置路径在实施时按实际保存行为登记，不把整个游戏目录遍历当作测试设计。

## 4. 回退与交付边界

原型开始时保留目标 DLL／配置的版本、长度与 SHA256；实际安装另按当次授权执行。管理模块移除需要退出游戏，不进行局内 DLL 热卸载。若原型修改了目标 MOD 接口，回退同时评估目标 DLL 与配置兼容性，不承诺只删管理 DLL 就能还原所有历史文件。

C1 实际新增 `PreLuna.ModControl.dll` 与 `Definitions/Module_PreLuna.ModControl_Group_Definition.json`；C3 之后才可能有目标 MOD DLL 的接口改动。正式文件、版本、SHA256、交付位置和游戏相对路径在产生并验证后逐项列明。此处不提供不存在产物的下载／安装链接，不将全仓 out 或其他 MOD 的回归 DLL 纳入交付。

开发流程沿用审查暂存、显式更新锁、根维护／仓核验和实际构建测试；提交、远端建仓、推送、游戏安装及 Release 发布分别按当次授权执行。整合仓 Repositories／LocalWorkspace 按真实源码组合登记，PublishedBaseline 不变。
